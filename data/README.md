# data/

Datos del sitio. `catalogo.json` y `atlas-data.js` se **generan** con `scripts/build_catalog.py`; no se editan a mano. `fuentes/` guarda las descargas oficiales; `siglas.json`, `agencias.json` (ficha de cada agencia en 6 idiomas, T87), `sistema_onu.json`, `historia.json` y `hoja_ruta.json` son contenido propio (CC BY 4.0) y sí se editan.
